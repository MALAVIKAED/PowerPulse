## About

PowerPulse is an intelligent outage management platform designed to improve communication between citizens and electricity authorities during Kerala's monsoon season. It combines outage reporting, weather monitoring, repair tracking, analytics, and community support into a single, user-friendly interface.

---

## Key Features

- Real-time power outage monitoring
- Interactive Kerala outage map
- AI-based outage prediction
- Citizen issue reporting
- Repair progress tracking
- Live weather monitoring
- Community support locations
- Analytics dashboard
- Smart notifications
- Responsive and accessible interface
